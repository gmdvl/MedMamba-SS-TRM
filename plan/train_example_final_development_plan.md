# Final Development Plan for `train_example.py`

## Goal

Transform `train_example.py` from a demonstration script into a
research-grade, reproducible training framework centered on **NumPy
(`.npy`) datasets** generated by `prepare_histologyhsi_bc-new.py`.

## Canonical Workflow

``` text
Raw Dataset
    │
    ▼
prepare_histologyhsi_bc-new.py
    │
    ▼
X_train.npy
y_train.npy
X_test.npy
y_test.npy
wavelengths.npy (HSI only)
    │
    ▼
train_example.py
    │
    ▼
Experiment Manager
```

## Phase 0 -- Standardize the Data Pipeline

-   `.npy` is the only internal training format.
-   Replace ImageFolder as the primary workflow.
-   Support RGB `[N,H,W,3]` and HSI `[N,H,W,C]`.
-   Auto-discover `X_train.npy`, `y_train.npy`, `X_test.npy`,
    `y_test.npy`, and optional `wavelengths.npy`.
-   Validate shapes, dtypes, NaNs/Infs, label ranges, class balance, and
    wavelength consistency.
-   Produce `dataset_summary.json`.

## Phase 1 -- Refactor Architecture

-   Split into trainer, evaluator, metrics, checkpoint, logger, plots,
    profiler, report, and experiment manager modules.

## Phase 2 -- Experiment Manager

Create a timestamped experiment directory containing: - checkpoints/ -
logs/ - plots/ - predictions/ - reports/ - tensorboard/ - config.yaml -
dataset.json

## Phase 3 -- Configuration & Metadata

Record hardware, software, CLI arguments, dataset statistics,
preprocessing settings, random seeds, and Git commit.

## Phase 4 -- Logging

Save: - train.log - history.csv - metrics.json

Include epoch time, GPU memory, throughput, learning rate,
train/validation loss and accuracy.

## Phase 5 -- Checkpointing & Resume

Save: - latest.pt (every epoch) - best.pt - periodic checkpoints

Checkpoint contents: - model, optimizer, scheduler, scaler - epoch,
global step - RNG states - history - dataset checksum

Support automatic resume after interruption.

## Phase 6 -- Classification Metrics

Compute: - Accuracy - Balanced Accuracy - Precision - Recall - F1 -
ROC-AUC - PR-AUC - MCC - Cohen's Kappa - Confusion Matrix -
Classification Report

## Phase 7 -- Spectral Metrics

For models that reconstruct spectra: - SAM - SID - Spectral
Reconstruction Error - RMSE - MAE

For the current classifier: - Clearly mark these metrics as "Not
Applicable" unless a reconstruction head is added.

Also report band-selection metrics when available: - Selected
wavelengths - Band importance - Selection stability - Spectral coverage

## Phase 8 -- Reports

Generate: - PDF summary - CSV logs - JSON metrics - Prediction CSV -
Loss/accuracy plots - ROC and PR curves - Confusion matrix

## Phase 9 -- Performance Optimization

Focus on `.npy` datasets: - Memory-mapped loading - RAM caching for
small datasets - pin_memory - persistent_workers - prefetch_factor -
non_blocking transfers - Automatic batch-size estimation - Mixed
Precision (AMP) - torch.compile - Channels-last memory format - Gradient
checkpointing - Fused AdamW - cuDNN benchmark - TF32 - Asynchronous
checkpoint saving

## Phase 10 -- Advanced Features

-   TensorBoard
-   Early stopping
-   Multi-GPU (DDP)
-   Learning-rate finder
-   Warmup + cosine scheduler
-   Deterministic reproducibility

## Success Criteria

-   Works exclusively from `.npy` datasets.
-   Automatically resumes interrupted training.
-   Produces publication-quality reports.
-   Logs every experiment reproducibly.
-   Maximizes GPU utilization while minimizing memory usage.
